# Arrays, DOM e Eventos — Semana 04

Atividade de Desenvolvimento Web para praticar JavaScript com arrays, manipulação do DOM e eventos.

## Bloco 1 — Arrays

Foram utilizados os seguintes métodos:

- `forEach`: percorre os elementos de um array.
- `map`: cria um novo array a partir dos elementos do original.
- `filter`: cria um array com os elementos que atendem a uma condição.
- `reduce`: acumula os valores de um array, como na soma de preços.

## Bloco 2 — DOM

O JavaScript altera o título da página, acessa os parágrafos e adiciona itens à lista usando `querySelector`, `querySelectorAll`, `innerHTML`, `createElement` e `append`.

Também utiliza `classList` para destacar itens e marcar tarefas como concluídas.

## Bloco 3 — Eventos

O projeto utiliza `addEventListener` para identificar cliques, movimentos do mouse, digitação e envio do formulário.

O *Event Delegation* permite controlar os cliques de todos os itens da lista com um único evento no elemento pai. Isso evita criar vários listeners e permite que itens adicionados depois também funcionem.

## Como executar

Abra o arquivo `index.html` no navegador e pressione F12 para visualizar os resultados no Console.
